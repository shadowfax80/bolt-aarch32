# Agent instructions

This repo is worked on by two agents, Codex and Claude. Before any work, read
[docs/HANDOFF.md](docs/HANDOFF.md) and follow its rules: respect the live-tree
lock, claim an open item before starting it (open items are a shared pool,
not assigned by origin), export one overlay per item, and append a handoff
log entry before stopping. Coverage is measured by
scripts/lk_coverage_report.py.
